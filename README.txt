BLUVERSE — My Creative Universe

วิธีเปิดดูบน iPhone:
1. แตกไฟล์ ZIP ในแอป Files
2. เปิดโฟลเดอร์ Bluverse แล้วแตะ index.html
3. หากต้องการให้เป็นเว็บไซต์ออนไลน์ ใช้ GitHub Pages:
   - สร้าง repository ใหม่ชื่อ bluverse
   - อัปโหลดไฟล์และโฟลเดอร์ทั้งหมดใน ZIP นี้
   - ไปที่ Settings > Pages
   - เลือก Deploy from a branch และเลือก main / root
   - รอ GitHub เผยแพร่เว็บไซต์

หมายเหตุ:
- การเพิ่มผลงานในหน้าเว็บต้นแบบจะเก็บข้อมูลใน localStorage ของเบราว์เซอร์เครื่องนั้น
- Chelsea Story อยู่ใน projects/chelsea_story.html และลิงก์จากหน้าแรกแล้ว
- เมื่อเพิ่มโปรเจกต์ใหม่ที่เป็นไฟล์ HTML ให้ใส่ไฟล์ไว้ในโฟลเดอร์ projects และกรอกลิงก์แบบ projects/ชื่อไฟล์.html
